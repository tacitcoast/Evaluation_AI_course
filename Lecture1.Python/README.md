## Задание 1. Оценка классификатора спама

Классификатор разметил 15 писем: `1` — спам, `0` — не спам. Рядом правильные ответы и темы писем. Посчитать точность и разобрать ошибки.

Считала руками, без библиотек: `len()` для общего числа, циклы со счётчиком для количества спама, `zip()` для сравнения предсказаний с правильными ответами попарно. Ошибки искала циклом по индексам — индекс нужен и для номера письма, и чтобы достать тему из третьего списка.

```
Total emails: 15
Predicted as spam: 8
Actually spam: 8
Model accuracy: 73.3%
Total errors: 4 out of 15
```

Выводы:

- модель назвала спамом 8 писем, и настоящего спама тоже ровно 8 — но это ничего не значит. Два обычных письма ушли в спам, ровно два спама прошли мимо, ошибки скомпенсировали друг друга;
- если смотреть только на общее количество, модель выглядит безупречной, хотя ошиблась в четырёх случаях из пятнадцати;
- ошибки надо считать по типам: потерянное рабочее письмо дороже, чем реклама во входящих.

## Задание 2. Анализ результатов экспериментов

Восемь экспериментов по обучению моделей: идентификатор, название, точность, время обучения, размер выборки. Положить в CSV, прочитать обратно и посчитать сводку.

Запись и чтение через модуль `csv`. Функция `read_experiments()` собирает из каждой строки словарь — ключ это название колонки. Числа из файла приходят текстом, поэтому точность и время переводятся в `float()`, размер выборки в `int()`: без этого сравнение `> 0.9` сравнивало бы строки посимвольно. Фильтр по BERT работает через `in` — оператор ищет вхождение подстроки, поэтому ловит и `BERT-small`, и `BERT-large`.

```
Total experiments: 8
Average accuracy: 0.863
Best experiment: exp_006 (GPT-2) - accuracy 0.945

Experiments with accuracy above 0.9: 3
BERT experiments: 4
Average BERT accuracy: 0.875
```

Выводы:

- порог 0.9 прошли три эксперимента из восьми, лучший результат у GPT-2;
- каждую модель обучали дважды, на 1000 и на 2000 примерах. Данные помогли всем, но неодинаково: GPT-2, BERT-large и Random-Forest прибавили около 0.02, а BERT-small всего 0.005 — ему добавка почти ничего не дала;
- BERT-large учится 182 секунды против 45 у BERT-small — вчетверо дольше ради 0.04–0.06 точности. Выбор модели это компромисс, и по одной колонке с точностью его не сделать.
