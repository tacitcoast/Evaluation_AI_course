# Задание 1. Оценка классификатора спама

Классификатор писем разметил 15 писем: `1` — спам, `0` — не спам. Рядом лежат правильные ответы (`true_labels`) и темы писем. Нужно оценить, насколько хорошо модель справилась.

Что требуется сделать:

1. Подсчитать общее количество писем
2. Найти количество писем, которые модель классифицировала как спам
3. Найти количество писем, которые действительно являются спамом
4. Написать функцию `calculate_accuracy(predictions, true_labels)`, которая возвращает точность модели
5. Вычислить и вывести точность в процентах
6. Найти все случаи, где модель ошиблась, и для каждой ошибки вывести номер письма, тему, что предсказала модель и что было на самом деле

Сдаётся файл `.ipynb`.

## Как решалось

Задания 1–3 — это подсчёт. Общее количество берётся через `len()`, количество спама — циклом со счётчиком: перебираем список и увеличиваем счётчик там, где значение равно `1`.

Задание 4 — функция. Внутри `zip()` соединяет два списка в пары «предсказание — правильный ответ», счётчик считает совпадения, функция возвращает долю совпадений от общего числа. В начале стоит проверка длин списков: если они разной длины, дальше считать бессмысленно, поэтому выбрасывается `ValueError`.

Задание 5 — форматирование. Доля от 0 до 1 умножается на 100, `:.1f` в f-строке оставляет один знак после запятой.

Задание 6 — цикл по индексам. `range(len(predictions))` даёт номера позиций, по одному индексу сразу достаются предсказание, правильный ответ и тема письма. Условие `!=` отбирает только те позиции, где модель ошиблась. Метки `1`/`0` переводятся в слова через `if/else` прямо в цикле, чтобы в отчёте читалось `spam` вместо `1`.

# Задание 2. Анализ результатов экспериментов

Есть таблица из восьми экспериментов: идентификатор, название модели, точность, время обучения и размер обучающей выборки. Нужно положить её в CSV, прочитать обратно в Python и посчитать по ней сводку.

Задачи:

1. Создать файл CSV с данными
2. Написать функцию `read_experiments(filename)`, которая читает файл и возвращает список словарей — по одному словарю на эксперимент
3. Создать список экспериментов с точностью выше 0.9
4. Найти все эксперименты с BERT-моделями (содержат `BERT` в названии)
5. Написать функцию, которая сохраняет сводный отчёт в файл `report.txt`

Сдаётся архив: файл `.ipynb` и файл CSV.

## Как решалось

Задание 1 — запись CSV через модуль `csv`. Данные лежат списком списков, первый список — строка заголовков. `csv.writer` записывает их построчно. Параметр `newline=""` нужен, чтобы в файле не появлялись лишние пустые строки. Кодировку не указываем: в данных только латиница и цифры, а для них системная кодировка по умолчанию подходит везде.

Задание 2 — чтение. `csv.reader` возвращает каждую строку файла как список строк. `next(reader)` пропускает первую строку с заголовками. Дальше из каждой строки собирается словарь: ключ — название колонки, значение — соответствующий элемент. Числа приходят из файла текстом, поэтому точность и время переводятся в `float()`, а размер выборки в `int()`. Готовые словари накапливаются в списке, функция возвращает его.

Задание 3 — фильтрация по числу: цикл со сравнением `> 0.9` и `append()` подходящих словарей в новый список.

Задание 4 — фильтрация по тексту: оператор `in` проверяет, встречается ли подстрока `BERT` внутри названия модели. Он ловит и `BERT-small`, и `BERT-large`, поскольку ищет вхождение, а не полное совпадение.

Задание 5 — отчёт. Функция принимает три готовых списка, считает среднюю точность (сумма делить на количество), находит лучший эксперимент перебором с запоминанием максимума и отдельно считает среднюю точность BERT-моделей. Файл открывается в режиме `"w"`, строки пишутся через `file.write()`; `\n` в конце каждой строки — перенос, сам `write()` его не добавляет в отличие от `print()`.
